# Forma Studio: Photo & Type

Create layered photo compositions, expressive typography, and hand-drawn details on iPhone and iPad.

## Help and support

[Report an issue or ask a question](https://github.com/EmbeddedTony/forma-studio-support/issues/new). Include your device model, iOS/iPadOS version, app version, and the steps that reproduce the problem. Issues are public: do not include private photos, project files, payment details, or other sensitive information.

## Getting started

- Tap a layer to select it. Drag to move, pinch to resize, and rotate with two fingers.
- Open layer properties to change text, photo effects, masks, borders, opacity, or blending.
- To remove a layer, select it and tap **Delete layer** in its properties. Unlock it first if necessary. Undo restores a deleted layer.
- Use **Draw** for PencilKit pens, markers, pencils, erasers, and ruler. Apple Pencil is supported on compatible iPads.
- Use the project menu to save an editable `.forma` file to Files. One current project autosaves on the device. Save copies before starting another design.
- Export PNG or JPG to Photos or the share sheet. Free exports have no watermark and a maximum longest edge of 2048 pixels. Pro allows larger exports up to 8192 pixels, subject to the selected canvas and scale.
- Imported fonts are available for the current app session; import them again after restarting. Use fonts and images you have permission to use.

## Free and Forma Pro

Free includes five layers, text gradients, drawing, basic photo adjustments, Gaussian blur, and five looks including Original. **Forma Pro** is an optional one-time Apple In-App Purchase for up to 150 layers, all 24 looks and six blur modes, extruded typography, layer blend modes, automatic photo layouts, and larger exports. The app displays your local App Store price before purchase. There is no subscription.

One Pro purchase works on iPhone and iPad signed into the same Apple Account. Open **Project options → Unlock Forma Pro → Restore Purchases** if a previous purchase is missing. Apple handles payments and refund requests. Future paid cloud services, if introduced, are separate from this local editor purchase.

Existing projects can still open without Pro. Premium settings already in a project remain visible; changing premium settings requires Pro. The supplied layered example is available to try for free.

## AI availability

AI writing suggests original headlines and captions on-device. It requires iOS/iPadOS 26 or later, an Apple Intelligence-compatible device, Apple Intelligence enabled, a supported language and region, and Apple's model downloaded. It does not generate or edit photos. All other editing tools work on supported devices running iOS/iPadOS 18 or later.
